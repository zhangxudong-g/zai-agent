## 🤖 Agent 的"确认系统"

在 Agent 里，工具执行时的"用户确认"是通过**中断 (Interrupt)** 机制实现的：

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   🔧 工具执行                                                    │
│       │                                                         │
│       ├──→ 中间件说："等等，这是危险操作！"                     │
│       │                                                         │
│       ├──→ 🚨 触发中断！暂停！                                  │
│       │                                                         │
│       └──→ 👤 等用户确认                                        │
│                   │                                             │
│                   ├──→ [确认] → 继续执行 ✅                     │
│                   │                                             │
│                   └──→ [取消] → 停止 ❌                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 🔧 怎么用？

### 1️⃣ 写一个"确认中间件"

```python
# 想象中间件就是贴在工具上的"安检员"
class ConfirmMiddleware:
    """危险操作需要确认的中间件"""
    
    def __init__(self):
        # 注册到 ExecuteToolStage.Input 阶段
        # 意思是：在工具真正执行"之前"检查
        ExecuteToolStage.Input(self.on_tool_call)
    
    async def on_tool_call(self, ctx, next_fn):
        # 🔍 检查是不是危险操作
        if ctx.tool_use["name"] in ["delete_file", "drop_table"]:
            
            # 🚨 触发中断！
            ctx.interrupt(
                name="dangerous_operation",      # 中断的名字
                reason="即将执行危险操作，确认吗？",  # 给用户看的原因
            )
        
        # ✅ 没事，继续执行
        return next_fn(ctx)
```

### 2️⃣ 注册到 Agent

```python
# 创建 Agent，加上确认中间件
agent = Agent(
    model="claude",
    tools=[删除文件, 清空数据库, 格式化硬盘],  # 🔥 危险工具
    plugins=[ConfirmMiddleware()]  # ⚠️ 给危险操作加个"确认关卡"
)
```

### 3️⃣ 用户调用

```python
# 用户让 Agent 删除文件
result = agent("删除 /tmp/important.txt")

# 结果... 不是直接删除！
# 而是返回了一个"中断"
print(result.stop_reason)  # "interrupt"  ← 意思是"暂停了！"
print(result.interrupts)   # [Interrupt(name="dangerous_operation", ...)]
```

### 4️⃣ 显示给用户

```python
# 你的代码里可以这样展示
for interrupt in result.interrupts:
    print(f"⚠️ {interrupt.reason}")
    print("请确认是否继续...")

# 等待用户点击 [确认] 或 [取消]
```

### 5️⃣ 用户确认后继续

```python
# 用户点了 [确认]
# 再次调用 Agent，把确认结果传进去

result = agent({
    "interruptResponse": {
        "dangerous_operation": "确认"  # ← 告诉 Agent：用户确认了
    }
})

# 这次才会真正删除！
print(result.message)  # "文件已删除" ✅
```

## 🤔 为什么需要中断机制？

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  问题：AI 可能乱执行危险操作！                                   │
│                                                                 │
│  例子：                                                          │
│  👤 用户："帮我整理下文件夹"                                    │
│  🤖 AI：      "好的！rm -rf /* 清理一下！" 💥💥💥            │
│                                                                 │
│  如果没有确认机制：                                              │
│  ❌ 系统被删光了！                                              │
│                                                                 │
│  有确认机制后：                                                  │
│  ✅ AI 说："我要删文件，确认一下？"                             │
│  ✅ 你说："等等！我来检查下..."                                  │
│  ✅ 发现不对劲："取消！"                                        │
│  ✅ 系统保住了！                                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 📝 小结

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   🔒 用户确认机制 = 中断 (Interrupt) 机制                       │
│                                                                 │
│   工作原理：                                                    │
│                                                                 │
│   1️⃣ 中间件检测到需要确认的操作                                │
│       │                                                         │
│       ▼                                                         │
│   2️⃣ 调用 ctx.interrupt() 触发中断                            │
│       │                                                         │
│       ▼                                                         │
│   3️⃣ Agent 暂停，返回中断信息                                  │
│       │                                                         │
│       ▼                                                         │
│   4️⃣ 应用展示给用户，等用户确认                                │
│       │                                                         │
│       ▼                                                         │
│   5️⃣ 用户确认后，再次调用 Agent                                │
│       │                                                         │
│       ▼                                                         │
│   6️⃣ Agent 检查确认，继续执行 ✅                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## 🎉 总结

**工具执行需要确认** 就是：

> 🤖 AI："我要执行危险操作，等你确认！"
> 
> 👤 用户："好的，我看看... 没问题，确认！"
> 
> 🤖 AI："收到！执行！" ✅

**核心就是：中断 → 等确认 → 继续执行** 🔄
