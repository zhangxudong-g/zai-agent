# 🔄 核心事件循环详解

## 核心理解

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   🤖 模型 = 决定者（决定要不要用工具、用什么工具）              │
│                                                                 │
│   🔄 Agent = 执行者（按照模型的决定去执行）                     │
│                                                                 │
│   🔁 循环 = 模型决定 → Agent执行 → 模型决定 → Agent执行 → ...  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## 详细流程

```
                    ┌─────────────────┐
                    │   开始！        │
                    └────────┬────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│              🔄 事件循环 (可以递归多次)                          │
│                                                                 │
│    ┌────────────────────────────────────────────────────────┐  │
│    │                                                        │  │
│    │   ① 🤖 调用模型（发送消息给大脑）                       │  │
│    │                                                        │  │
│    │         ┌───────────────────────────────┐              │  │
│    │         │ 模型思考后返回：              │              │  │
│    │         │                               │              │  │
│    │         │   情况A: "end_turn"          │              │  │
│    │         │   → 回答用户，结束！ ✅      │              │  │
│    │         │                               │              │  │
│    │         │   情况B: "tool_use"          │              │  │
│    │         │   → 让我用工具！🔧           │              │  │
│    │         │                               │              │  │
│    │         │   (模型会告诉我要用哪个工具， │              │  │
│    │         │    以及工具的参数是什么)      │              │  │
│    │         │                               │              │  │
│    │         └───────────────────────────────┘              │  │
│    │                    │                                   │  │
│    │                    ▼                                   │  │
│    │   ② 🔧 Agent 执行工具（按照模型的指示）                 │  │
│    │       ┌─────────────────────────────────┐             │  │
│    │       │  工具执行中...                  │             │  │
│    │       │  工具返回结果...                │             │  │
│    │       └─────────────────────────────────┘             │  │
│    │                    │                                   │  │
│    │                    │ 把工具结果告诉模型                   │  │
│    │                    │                                   │  │
│    │                    ▼                                   │  │
│    │   ③ 🔄 回到第①步（再次调用模型）                       │  │
│    │       "工具用完了，模型你看看结果，告诉我下一步怎么做？"  │  │
│    │                                                        │  │
│    └────────────────────────────────────────────────────────┘  │
│                             │                                 │
│              ┌─────────────┴─────────────┐
│              ▼                         ▼
│    ┌─────────────────┐       ┌─────────────────┐
│    │   模型说结束！   │       │  继续用工具！   │
│    │   返回结果 ✅    │       │  继续循环 🔄   │
│    └─────────────────┘       └────────┬────────┘
│                                        │
│                                        ▼
│                               回到第①步继续...
└─────────────────────────────────────────────────────────────────┘
```

## 回答你的问题

### 问题1：循环等待模型返回最终结果？

**是的，但更准确的说法是：**

```
❌ 不准确：循环"等待"
✅ 准确：循环"调用"

每次循环：
  1. 调用模型 → 等待响应
  2. 检查响应 → 如果是 end_turn，结束
  3. 如果是 tool_use → 执行工具
  4. 再次调用模型（带上工具结果）
```

### 问题2：工具选择与调用都是模型决定的？

**是的！**

```python
# 模型返回的响应示例

# 情况A：不需要工具
{"role": "assistant", "content": [{"text": "你好！很高兴为你服务。"}], "stop_reason": "end_turn"}

# 情况B：需要工具
{
    "role": "assistant",
    "content": [
        {
            "toolUse": {
                "name": "calculator",  # ← 模型决定的工具名
                "input": {"expression": "2+2"},  # ← 模型决定的参数
            }
        }
    ],
    "stop_reason": "tool_use",
}
```

## 简单总结

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   🤖 模型 = 思考者/决策者                                       │
│      │                                                          │
│      │  决定要不要用工具                                         │
│      │  决定用哪个工具                                          │
│      │  决定工具的参数                                           │
│      ▼                                                          │
│   🔧 Agent = 执行者                                              │
│      │                                                          │
│      │  执行模型指定的工具                                       │
│      │  把结果返回给模型                                         │
│      ▼                                                          │
│   🔁 循环 = 直到模型说"回答完了"                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## ReAct 模式

这就是著名的 **ReAct 模式**：

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ReAct = Reason（推理）+ Act（行动）                           │
│                                                                 │
│   1. Reason（推理）= 模型思考                                  │
│      "用户问的是什么？我需要做什么？需要用工具吗？"              │
│                                                                 │
│   2. Act（行动）= 执行动作                                      │
│      "调用搜索工具查找信息"                                      │
│                                                                 │
│   3. 重复 Reason + Act，直到完成                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 实际例子

### 用户问："今天北京天气怎么样？"

```
第1轮：
┌─────────────────────────────────────────────────────────────┐
│  Reason: 模型思考                                            │
│  "用户问天气，我需要调用天气工具"                            │
│                                                             │
│  Act: 模型返回 tool_use {"name": "weather", "city": "北京"} │
│                                                             │
│  Agent: 执行天气工具，获取天气数据                            │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
第2轮：
┌─────────────────────────────────────────────────────────────┐
│  Reason: 模型思考                                            │
│  "工具返回了天气数据，今天晴天，25度"                         │
│  "我可以回答用户了"                                          │
│                                                             │
│  Act: 模型返回 end_turn "今天北京天气晴朗，气温25度"           │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
      结束！
```

### 用户问："帮我算 2+2 等于多少？"

```
第1轮：
┌─────────────────────────────────────────────────────────────┐
│  Reason: 模型思考                                            │
│  "用户问数学，我可以直接回答"                                │
│                                                             │
│  Act: 模型返回 end_turn "2+2=4"                             │

         │

```

### 复杂任务："帮我查下苹果股价，然后算算涨了多少"

```
第1轮：
┌─────────────────────────────────────────────────────────────┐
│  Reason: "用户要查股价，我需要调用搜索工具"                   │
│  Act: tool_use {"name": "search", "query": "苹果股价"}      │
│  Agent: 执行搜索，获取股价 150 美元                          │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
第2轮：
┌─────────────────────────────────────────────────────────────┐
│  Reason: "有了当前股价，需要昨天的价格才能算涨幅"               │
│  Act: tool_use {"name": "search", "query": "苹果昨天股价"}   │
│  Agent: 执行搜索，获取昨天股价 145 美元                       │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
第3轮：
┌─────────────────────────────────────────────────────────────┐
│  Reason: "现在有今天150和昨天145，可以算了"                   │
│  "涨幅 = (150-145)/145 = 3.45%"                            │
│  Act: end_turn "苹果今天股价150美元，昨天145美元，上涨3.45%"   │
└─────────────────────────────────────────────────────────────┘
         │
         ▼
      结束！
```
