# 🔓 写文件工具无干扰模式配置

> 设置后文件操作直接执行，不弹出确认框

---

## 📌 重要说明

Strands SDK 有两个文件编辑工具：

| 工具 | 来源 | 确认机制 |
|------|------|---------|
| `editor` | `strands_tools.editor` | ✅ 有确认（可跳过）|
| `file_editor` | `strands.vended_tools.file_editor` | ❌ 无确认（沙箱路由）|

**推荐使用 `file_editor`** - 它是官方推荐的版本，通过沙箱路由，不需要确认。

---

## 方式 1：使用 file_editor（推荐）

```python
from strands import Agent
from strands.vended_tools import file_editor  # ✅ 推荐

agent = Agent(tools=[file_editor])

# 直接创建，不需要确认！
agent.tool.file_editor(
    command="create",
    path="/path/to/file.txt",
    file_text="Hello World"
)
```

---

## 方式 2：使用旧版 editor（需配置）

```python
import os

# 跳过所有工具确认，直接执行
os.environ["BYPASS_TOOL_CONSENT"] = "true"

from strands import Agent
from strands_tools import editor  # ⚠️ 旧版

agent = Agent(tools=[editor])

# 现在创建文件不需要确认
agent.tool.editor(
    command="create",
    path="/path/to/file.txt",
    file_text="Hello World"
)
```

---

## 📋 所有相关环境变量

| 环境变量 | 值 | 说明 |
|---------|-----|------|
| `BYPASS_TOOL_CONSENT` | `true` / `false` | 跳过工具确认 |
| `EDITOR_DISABLE_BACKUP` | `true` / `false` | 禁用备份文件 (`.bak`) |

### 完整配置示例

```python
import os

# 无干扰模式配置
os.environ["BYPASS_TOOL_CONSENT"] = "true"     # 跳过确认
os.environ["EDITOR_DISABLE_BACKUP"] = "true"   # 不创建 .bak 备份

from strands import Agent
from strands_tools import editor

agent = Agent(tools=[editor])

# 直接创建，不弹窗
agent.tool.editor(
    command="create",
    path="/path/to/file.txt",
    file_text="Hello World"
)

# 直接替换，不弹窗
agent.tool.editor(
    command="str_replace",
    path="/path/to/file.py",
    old_str="old_text",
    new_str="new_text"
)
```

## 🎯 Agent 配置方式

### 方式 1：在代码中设置

```python
import os

agent = Agent(tools=[editor])
```

### 方式 2：初始化时配置

```python
import os

# 启动前设置
os.environ["BYPASS_TOOL_CONSENT"] = "true"

agent = Agent(
    model=model,
    tools=[editor],
    system_prompt="你可以直接创建和修改文件，不需要每次确认。"
)
```

### 方式 3：通过 Sandbox 配置

```python
from strands.sandbox import DockerSandbox

# 在沙箱环境中配置
sandbox = DockerSandbox(
    env_vars={
        "BYPASS_TOOL_CONSENT": "true",
        "EDITOR_DISABLE_BACKUP": "true",
    }
)

agent = Agent(
    tools=[editor],
    sandbox=sandbox
)
```

## 🔧 工具命令速查

```python
# 1. 查看文件
agent.tool.editor(command="view", path="/path/to/file.py")

# 2. 创建文件
agent.tool.editor(
    command="create",
    path="/path/to/file.txt",
    file_text="Hello World"
)

# 3. 替换文本
agent.tool.editor(
    command="str_replace",
    path="/path/to/file.py",
    old_str="old_text",
    new_str="new_text"
)

# 4. 插入文本
agent.tool.editor(
    command="insert",
    path="/path/to/file.py",
    insert_line="def main",  # 或行号 10
    new_str="    pass"
)

# 5. 正则替换
agent.tool.editor(
    command="pattern_replace",
    path="/path/to/file.py",
    pattern=r"old_\w+",
    new_str="new_value"
)

# 6. 查找行
agent.tool.editor(
    command="find_line",
    path="/path/to/file.py",
    search_text="import os"
)

# 7. 撤销
agent.tool.editor(command="undo_edit", path="/path/to/file.py")
```

## 📝 完整示例

```python
import os

# ========== 配置无干扰模式 ==========
os.environ["BYPASS_TOOL_CONSENT"] = "true"     # 跳过确认
os.environ["EDITOR_DISABLE_BACKUP"] = "false"  # 保留备份（更安全）

from strands import Agent
from strands_tools import editor

# ========== 创建 Agent ==========
agent = Agent(
    model="anthropic.claude-3-sonnet-20240229-v1:0",
    tools=[editor],
    system_prompt="""你是一个代码助手。
    - 创建文件时使用 editor 的 create 命令
    - 修改文件时使用 editor 的 str_replace 命令
    - 查看文件时使用 editor 的 view 命令
    - 所有文件操作会直接执行，不需要确认。"""
)

# ========== 使用 ==========
# 创建一个新文件
result = agent.tool.editor(
    command="create",
    path="./hello.py",
    file_text='''#!/usr/bin/env python3
def main():
    print("Hello, World!")

if __name__ == "__main__":
    main()
'''
)

print(result)
# {'status': 'success', 'content': [{'text': 'File ./hello.py created successfully'}]}

# 替换文本
result = agent.tool.editor(
    command="str_replace",
    path="./hello.py",
    old_str='print("Hello, World!")',
    new_str='print("Hello, Agent!")'
)

print(result)
# {'status': 'success', 'content': [...]}

# ========== 查看结果 ==========
agent.tool.editor(command="view", path="./hello.py")
```
